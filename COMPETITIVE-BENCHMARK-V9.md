# Briefs V9 competitive authority benchmark

V9 is measured on whether a high-quality answer can become a durable reference object rather than disappearing inside a chat transcript.

## Acceptance bar
- Canonical public URL for durable Briefs.
- Machine-readable metadata with real modified/verified dates.
- Evidence links visible at claim level.
- No indexing of ephemeral search-result or personal-account pages.
- Structured sitemap and RSS surfaces.
- Current-news sitemap only for recent database-backed published Briefs.
- Public structured API that returns the same BriefResult contract used by the product.
- User-controlled Markdown, CSV and JSON export.
- Listen mode that degrades cleanly when browser speech synthesis is unavailable.
- Email delivery is opt-in by configuration and cannot take down the daily intelligence run.

## Differentiation
General research assistants are primarily session-oriented. Briefs is aiming for a durable public knowledge layer where claims, evidence, freshness, revisions and historical state can be inspected over time. V9 makes that architecture externally visible.
