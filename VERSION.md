# Briefs.blog V4.1 — Autonomous Editorial Foundation

Version: **0.4.0**

V4 is a clean recovery-and-upgrade release. It preserves the V2 reliability layer and V3 knowledge layer while adding the first operational editorial-maintenance system.

## Implemented in V4

- repaired V3 runtime/config/import damage
- section-level editorial revision proposals
- evidence-aware review policy
- editorial queue and admin cockpit
- approve / reject / publish / rollback actions
- immutable publication snapshots
- correction records
- claim-to-section dependency awareness
- citation synchronization foundation
- automatic freshness recalculation
- internal-link suggestion foundation
- transactional publication path
- rollback path
- V4 orchestration job integrated with the durable V2 queue
- simple `Brief me on` public surface preserved

See `SYSTEMS.md` for the complete product-system inventory so future versions do not silently drop planned engines.


## V4.1 UX stabilization
The Brief Me route is now an actual interactive briefing surface rather than a static explanatory landing page. See `V4.1.md`.
