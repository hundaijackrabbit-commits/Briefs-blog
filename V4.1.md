# Briefs.blog V4.1 — Interactive Briefing Surface

V4.1 removes the static detour from the core product. The homepage prompt now lands on an interactive briefing surface that immediately invokes `/api/brief` for the requested subject.

## Fixed
- `/brief-me?q=...` now automatically generates a live Brief instead of rendering a static explainer.
- Depth and perspective controls are wired into the Brief Request object.
- Loading, unavailable-database, evidence-gap, confidence, change, and key-number states are visible to the user.
- `/api/brief` reports a clear `DATABASE_NOT_CONFIGURED` state when the intelligence database is not connected.
- Health endpoint reports V4.1.
- validation npm scripts use a cross-platform Python launcher wrapper instead of hard-coding `python3`.

## Architecture preserved
V2 reliability, V3 knowledge/evidence/temporal intelligence, and V4 editorial/publishing systems remain intact. `SYSTEMS.md` remains the canonical inventory for future versions.
